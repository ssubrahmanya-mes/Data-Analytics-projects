# Data Analysis & Banking Dashboarding

**Technologies:** Python, SQL, Power BI, GitHub
**Duration:** October 2025

## Project Overview

Developed a Banking Data Analysis and Dashboarding project to analyze customer, transaction, and loan datasets. The project focused on extracting meaningful insights from banking data to support business decision-making and performance monitoring.

## Key Responsibilities

* Analyzed customer, transaction, and loan data using **Python** and **SQL**.
* Performed **data cleaning, preprocessing, and transformation** to improve data accuracy and quality.
* Wrote SQL queries to retrieve, filter, and analyze large datasets efficiently.
* Built interactive **Power BI dashboards** to visualize key banking metrics and financial trends.
* Generated actionable insights related to customer behavior, loan performance, and transaction patterns.
* Created reports and visualizations to support data-driven business decisions and operational performance tracking.
